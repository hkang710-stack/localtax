# 로컬링크 — 지역 탐색 (API 연동판)

청년 지방 창업 후보지를 비교하는 웹 서비스의 실행 가능한 프로토타입입니다.
공공 API 3종(상가상권정보·온통청년·KOSIS)을 연동하는 구조이며, **API 키가 없어도
예시값으로 바로 실행**되고, 키를 넣는 순간 해당 지표만 실데이터로 바뀝니다.

## 1. 실행 방법

필요한 것은 Node.js(18 이상) 하나뿐입니다. https://nodejs.org 에서 LTS 버전을 설치하세요.

```bash
cd locallink
node server.js
```

브라우저에서 http://localhost:3000 을 열면 지역 탐색 화면이 뜹니다.
화면의 지표 옆 작은 점이 **초록색이면 실데이터, 회색이면 예시값**입니다.

- `http://localhost:3000/api/health` — 어떤 API 키가 설정됐는지 확인
- `http://localhost:3000/api/regions` — 화면이 쓰는 원본 데이터(JSON)

## 2. 폴더 구조

```
locallink/
├── server.js            # 메인 서버 (외부 패키지 0개, node만으로 실행)
├── judge.js             # 세제혜택 판정 모듈 (인구감소지역 89곳·과밀억제권역·기회발전특구)
├── config/regions.js    # 비교 지역 8곳 설정 (행정코드·좌표·예시값)
├── collectors/
│   ├── sbiz.js          # 상가상권정보 → 시군구 음식점 수
│   ├── youth.js         # 온통청년 → 청년정책 수·목록
│   └── kosis.js         # KOSIS → 청년 인구 비율 (표 설정 필요, 아래 참고)
├── public/index.html    # 지역 탐색 화면
├── data/cache.json      # 수집 결과 캐시 (24시간, 자동 생성)
└── .env.example         # API 키 설정 양식
```

## 3. API 키 발급 (지표별로 독립적 — 하나씩 붙여도 됩니다)

`.env.example`을 복사해 `.env` 파일을 만들고, 발급받은 키를 붙여넣은 뒤
서버를 재시작하세요. 캐시를 지우려면 `data/cache.json`을 삭제하면 됩니다.

### 상가상권정보 (음식점 수) — 난이도 하, 가장 먼저 추천
1. data.go.kr 회원가입 → "소상공인시장진흥공단_상가(상권)정보" 검색 → 활용신청 (자동승인)
2. 마이페이지에서 **일반 인증키(Encoding)** 복사 → `.env`의 `SBIZ_API_KEY=`에 붙여넣기
3. 참고: 발급 직후에는 키 반영에 몇 시간 걸릴 수 있습니다.

### 온통청년 (청년정책) — 난이도 중
1. youthcenter.go.kr 회원가입 → 마이페이지 → Open API 인증키 신청 (담당자 승인 후 발급)
2. `.env`의 `YOUTH_API_KEY=`에 붙여넣기
3. 이 API는 개편이 잦습니다. 호출이 실패하면 온통청년 Open API 가이드에서 최신
   엔드포인트·파라미터명을 확인하고 `collectors/youth.js` 상단의 `BASE`와 파라미터를 수정하세요.

### KOSIS (청년 인구 비율) — 난이도 상, 마지막에 붙이세요
1. kosis.kr/openapi 에서 인증키 발급
2. KOSIS는 통계표마다 파라미터가 달라서, 원하는 표(주민등록인구 연령별)를 KOSIS에서 연 뒤
   '공유서비스(OpenAPI)' 버튼으로 **그 표의 호출 URL을 복사**하는 방식이 가장 확실합니다.
3. 복사한 URL 구조에 맞게 `collectors/kosis.js`의 `buildUrl()`과 집계 부분을 완성하세요.
   (현재는 골격만 있고, 미완성 상태에서는 자동으로 예시값을 씁니다)

## 4. 알아둘 한계

- **임대료는 아직 예시값입니다.** 국토부 실거래가 API 연동이 다음 과제입니다.
- **시군구 코드 확인 필요.** 강원(42→51)·전북(45→52) 특별자치도 출범으로 코드가
  바뀌었습니다. 실데이터 연동 전에 code.go.kr에서 `config/regions.js`의 코드를 검증하세요.
- **경쟁지수는 단순화된 값입니다.** 현재는 음식점 수 기반이며, 실서비스에서는
  인구 대비(천 명당 업소 수)로 바꿔야 지역 간 비교가 공정해집니다.
- **점수 공식은 임의 가중치입니다.** `server.js`의 `scoreRegions()`에서
  임대료 25% / 경쟁 25% / 청년 20% / 정책 15% / 혜택 15%로 잡았고, 조정 가능합니다.
- 공공 API 호출 제한(보통 일 1,000건)이 있어 24시간 캐시를 씁니다.

## 5. 다음 단계 후보

혜택 계산기·답사 코스 화면 연결 → 지자체 지원사업 상세(접수 기간 포함) 수집.

## 6. 배포하기 (GitHub + Render 무료 플랜)

1. **GitHub 저장소 만들기** — github.com 가입 → New repository → 이름 locallink, Public 선택.
2. **코드 올리기** — 저장소 화면의 "uploading an existing file" 링크 → locallink 폴더 안의
   파일·폴더를 전부 드래그해서 업로드 → Commit. 단, `.env` 파일은 절대 올리지 마세요
   (키가 전 세계에 공개됩니다). `.gitignore`가 막아주지만 웹 업로드 시엔 직접 빼야 합니다.
3. **Render 연결** — render.com 에서 GitHub 계정으로 가입 → New → Web Service →
   방금 만든 저장소 선택.
4. **설정 3개** — Build Command는 비워두고, Start Command에 `node server.js`,
   Instance Type은 Free 선택 → Create.
5. **API 키 입력** — 서비스 대시보드 → Environment 탭 → `SBIZ_API_KEY` 등
   .env에 넣던 키들을 여기에 추가 (이래서 .env를 안 올려도 됩니다).
6. 몇 분 뒤 `https://이름.onrender.com` 주소가 생기면 배포 완료. 누구에게나 공유 가능합니다.

무료 플랜 특성: 15분간 접속이 없으면 서버가 잠들고, 다음 첫 접속이 30초~1분 느립니다.
포트폴리오·시연용으로는 충분하고, 상시 서비스가 필요해지면 유료 전환(월 $7)하면 됩니다.

### 한국관광공사 TourAPI (지역 사진) — 난이도 하
1. data.go.kr에서 "한국관광공사_국문 관광정보 서비스" 검색 → 활용신청(자동승인)
2. 일반 인증키(Encoding)를 `.env`의 `TOUR_API_KEY=`에 입력 후 서버 재시작
3. 카드의 선 그림 자리에 각 지역 관광지 실사진이 자동으로 깔립니다.
   지역명 키워드 검색 방식이라 행정코드 없이 91곳 전체에 적용돼요.
   호출 실패 시 collectors/tour.js 상단 주석을 참고해 서비스 버전(BASE)을 확인하세요.
